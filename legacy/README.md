# Legacy source

This directory preserves earlier projects that explain where Flyoobe came from but are no longer under active development.

## Flyby11

[`Flyby11`](Flyby11) is the complete classic Windows 11 upgrade assistant, including its native CPU compatibility helper.

Flyby11 was the starting point for Flyoobe: it helped otherwise usable Windows 10 PCs begin a Windows 11 upgrade when the normal setup path rejected their hardware. The code remains available for historical reference and for understanding the project's evolution.

It is **not actively maintained**. Windows setup behavior and requirements can change, so this source and old binaries should not be treated as current compatibility guidance.

Active development continues in Flyoobe 3.
