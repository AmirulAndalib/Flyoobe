# Flyoobe documentation

The public documentation is intentionally small and follows the current Flyoobe 3 architecture.

| Document | Purpose |
|---|---|
| [Setup Actions](setup-actions.md) | Install, author and review optional PowerShell actions |
| [Legacy projects](legacy.md) | Understand Flyby11, Flyoobe 2 and the source transition to Flyoobe 3 |
| [Changelog](../CHANGELOG.md) | User-facing history of the current release |
